# Sanyam Trehan — Portfolio

An interactive editorial portfolio for a frontend-focused senior full-stack engineer. The visual system combines Swiss editorial typography, strict rule-based layouts and one safety-orange signal color.

The site turns real engineering outcomes into working demonstrations:

- an assisted claim-review flow;
- playable reference tones for OpenTune;
- a deterministic checkout contention test;
- an HTTP range-streaming scrubber;
- an interface-state lab for loading, success and recoverable failure.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is written to `dist/` and can be deployed to any static host.
